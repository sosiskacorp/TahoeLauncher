**Tahoe Liquid Glass Launcher (`MacOSTahoe.exe`)** — полноценный нативный лаунчер и многозадачная среда рабочего стола для Windows 10/11 с аппаратным ускорением (GPU), выполненная 1 в 1 в эстетике **Liquid Glass (macOS Tahoe & Sequoia)** с поддержкой всех ключевых механизмов многозадачности Apple: **Mission Control**, **Spaces**, **Постановщик (Stage Manager)**, **Command + Tab** и **Split View**.

Собирается в единый сверхбыстрый исполняемый файл без внешних зависимостей, сторонних фреймворков и тяжёлых Electron/WebView-оболочек.

## ✨ Основные возможности многозадачности (1 в 1 с macOS)

### 1. 🗔 Mission Control (`F3`)
* **Мгновенный обзор всех открытых окон**: вызывается нажатием `F3`, кликом по иконке Mission Control в Dock или через верхнее меню.
* Разворачивает все запущенные приложения в единую элегантную галерею карточек с живыми иконками 256×256, заголовками окон и именами процессов.
* Поддерживает активацию в один клик, быстрое закрытие окон (`✕`), сворачивание всех окон и быстрый переход в режим **Split View**.

### 2. 🖥 Spaces (Пространства и рабочие столы)
* Верхняя интерактивная полоса рабочих столов внутри **Mission Control**.
* Позволяет создавать новые виртуальные рабочие столы кнопкой **«+»** (с интеграцией в нативные виртуальные столы Windows через `Win+Ctrl+D`).
* Быстрое переключение между пространствами в один клик и закрытие ненужных столов (`✕`).

### 3. 📑 «Постановщик» (Stage Manager — полный функционал 1 в 1)
* **Центральная сцена (Фокус на главном)**: Активное приложение располагается по центру экрана в чистом визуальном пространстве. Все остальные фоновые окна автоматически убираются на левую сторону.
* **Боковая полка миниатюр со стопками (Stacks)**:
  * Вертикальный стеклянный список недавних рабочих пространств (до 6 карточек) слева на экране.
  * **3D-эффект стопки**: несколько окон одного приложения (например, 2 окна Проводника или вкладки) аккуратно собираются в колоду с бэйджем количества окон (`● 2`, `● 3`).
  * Клик по стопке циклически переключает окна этой программы или выводит всю группу на первый план.
* **Группировка окон (Создание сценарных рабочих групп)**:
  * Можно объединять несколько приложений в одну группу (например, браузер + текстовый редактор).
  * **Drag & Drop или кнопка `＋ В сцену`**: перетащите миниатюру из левой панели в центр экрана или нажмите всплывающую кнопку `＋ В сцену`, чтобы прикрепить окно к текущей активной программе.
  * При переключении на объединенную группу все связанные окна выводятся на экран одновременно.
* **Взаимодействие с Рабочим столом**:
  * Кнопка **«🖥 Рабочий стол»** внизу панели отодвигает/минимизирует окна центральной сцены, мгновенно открывая доступ к файлам и папкам на рабочем столе. Повторный клик («↩ Вернуть сцену») возвращает рабочую группу.
* **Тонкая настройка и кастомизация (в окне `Win+Shift+A` и Пункте управления)**:
  * *Скрывать боковую панель миниатюр* — панель прячется и появляется только при подведении курсора к левому краю экрана.
  * *Автоскрытие в полноэкранном режиме* — при разворачивании любого окна на весь экран Stage Manager автоматически скрывается и возвращается при восстановлении окна.
  * *Группировать окна одного приложения* — собирать окна программы в аккуратную стопку.
  * *Центрировать активное окно* — автоматически выравнивать рабочее приложение по центру экрана.

### 4. 🔀 Command + Tab (Интерактивный App Switcher HUD)
* Аутентичный плавающий HUD-интерфейс в центре экрана, вызываемый сочетанием `Alt + Tab`.
* Удерживая `Alt`, нажимайте `Tab` для перехода вперёд, а сочетание `Shift + Tab` или клавишу **`~` (тильда / буква Ё)** — для перемещения назад (справа налево).
* Поддержка быстрых клавиш macOS прямо во время переключения:
  * **`Q`** — мгновенно завершить выбранное приложение (`WM_CLOSE`).
  * **`H`** — скрыть / свернуть выбранное окно.
  * **`Esc`** — отменить переключение без смены фокуса.
* Отпускание клавиши `Alt` мгновенно активирует выбранное окно.

### 5. ◫ Split View (Интерактивное разделение экрана)
* Режим работы с двумя приложениями бок о бок (50/50, 70/30 и произвольные пропорции).
* **Перетаскиваемый разделитель (Draggable Divider)**: плавающий разделитель с ручкой-пилюлей в стиле macOS, позволяющий мышью динамически менять ширину обоих окон одновременно в реальном времени.
* Двойной клик по разделителю сбрасывает пропорцию ровно на **50 / 50**.
* Стягивание к краю экрана автоматически завершает режим Split View.

## 🚀 Оболочка, Dock и Поиск

### 6. Полноэкранный лаунчер «Приложения» (клавиша `Win`)
* Низкоуровневый перехватчик клавиатуры (`WH_KEYBOARD_LL`) открывает полноэкранную сетку установленного софта по клавише `Win`.
* Автоматический фоновый трекинг установки/удаления программ (`FileSystemWatcher`).
* Фильтрация деинсталляторов, битых ссылок и служебных файлов.
* Категории: `Все`, `★ Избранное`, `Игры` (Steam/Epic), `Разработка`, `Интернет`, `Медиа и Офис`, `Система`.

### 7. Командная палитра и быстрый поиск (`Alt + Пробел`)
* Мгновенный поиск программ, математический калькулятор, веб-поиск Google (`?запрос`) и запуск команд терминала (`$команда`).

### 8. Интерактивный Dock Liquid Glass (120–165+ Гц)
* Физика волны без джиттера, анимация подпрыгивания иконок (`bounce`), живое добавление запущенных окон, закрепление/открепление (ПКМ) и умное автоскрытие в полноэкранных играх и окнах.

### 9. Верхняя строка меню (Top Menu Bar) & Пункт управления
* Фиксация рабочей области `SPI_SETWORKAREA`, системные меню в стиле Mac, мониторинг ОЗУ, переключатель раскладки (`RU`/`EN`), календарь и Пункт управления с плиткой **Stage Manager**.

## ⌨ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| **`F3`** | Открыть / закрыть **Mission Control & Spaces** |
| **`Alt + Tab`** | Открыть **Command + Tab** (HUD переключатель приложений) |
| **`Alt + ~` (тильда / Ё)** | Перемещение по списку приложений назад (справа налево) |
| **`Alt + Tab` → `Q`** | Завершить выбранное приложение прямо из HUD |
| **`Alt + Tab` → `H`** | Скрыть / свернуть выбранное приложение |
| **`Alt + Tab` → `Esc`** | Отменить переключение приложений |
| **`Win`** *(одиночное)* | Открыть / закрыть лаунчер **«Приложения»** |
| **`Alt + Пробел`** | Открыть **Командную палитру и Быстрый поиск** |
| **`Win + Shift + A`** | Открыть **Центр настроек лаунчера** |
| **`ПКМ` по иконке / приложению** | Контекстное меню (Закрепить, Избранное, Запуск от админа) |
| **`Esc`** | Закрыть любое активное окно / панель / меню |

## 🛠 Сборка и запуск

Проект **не требует** установки тяжеловесных IDE или сторонних SDK — сборка выполняется встроенным компилятором `.NET Framework 4.x` (`csc.exe`):

```powershell
git clone https://github.com/sosiskacorp/TahoeLauncher.git
cd TahoeLauncher

# Сборка из исходного кода
powershell -ExecutionPolicy Bypass -File .\build.ps1

# Запуск лаунчера
powershell -ExecutionPolicy Bypass -File .\apply.ps1
```

### Полный выход и возврат стандартной панели Windows 11
Нажмите **«Выход из лаунчера»** в меню яблока (или в окне настроек `Win+Shift+A`), либо выполните:
```powershell
powershell -ExecutionPolicy Bypass -File .\revert.ps1
```
