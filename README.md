**Tahoe Liquid Glass Launcher (`MacOSTahoe.exe`)** — полноценный нативный лаунчер и оболочка рабочего стола для Windows 10/11 с аппаратным ускорением (GPU), выполненная в эстетике **Liquid Glass (macOS 26 Tahoe)** с сохранением привычной логики и русских системных названий Windows.

Собирается в единый легковесный исполняемый файл (`~212 КБ`) без внешних зависимостей, сторонних фреймворков и тяжёлых WebView-оболочек.

## ✨ Основные возможности

### 1. 🚀 Полноэкранный лаунчер «Приложения» (по клавише `Win`)
* **Открытие по одиночному нажатию `Win`**: низкоуровневый перехватчик клавиатуры (`WH_KEYBOARD_LL`) блокирует стандартное меню «Пуск» и плавно открывает полноэкранную сетку приложений, при этом все системные сочетания (`Win+E`, `Win+R`, `Win+Shift+S`, `Win+I`, `Win+D`, `Win+L`) продолжают работать штатно.
* **Живой каталог установленных программ и игр**:
  * Автоматически сканирует системное и пользовательское меню «Пуск» (`CommonPrograms`, `Programs`), Рабочий стол, папки `Программы` и `Игры` (включая игры **Steam** и **Epic Games**).
  * Извлекает чёткие **256×256** иконки напрямую из `.exe` и `.ico` через нативный `SHDefExtractIconW`.
  * Умный фильтр отсекает деинсталляторы (`Uninstall`, `unins000`), установщики (`Setup`), справочные файлы (`Readme`, `Help`, `Website`), консольные SDK-утилиты и битые ярлыки.
  * **`FileSystemWatcher` + фоновая синхронизация**: новые установленные программы автоматически добавляются в каталог, а удалённые — сразу исчезают.
* **Категории и контекстное меню (ПКМ)**:
  * Фильтрация в 1 клик: `Все`, `★ Избранное`, `Игры`, `Разработка`, `Интернет`, `Медиа и Офис`, `Система`, `Программы`.
  * Правый клик по любому приложению позволяет: **Закрепить / открепить в Dock**, **Добавить в Избранное**, **Запустить от имени администратора**, **Открыть расположение файла** или **Скрыть из каталога**.

### 2. 🔍 Командная палитра и быстрый поиск (`Alt + Пробел`)
* Мгновенный поиск по всем установленным приложениям с навигацией клавишами `↑` / `↓`, запуском по `Enter`, запуском от имени администратора по `Ctrl + Shift + Enter` и открытием папки файла по `Tab`.
* **Системные команды** (префикс `>` или поиск по названию): открытие настроек лаунчера, переключение темы, показ/скрытие виджетов и значков стола, очистка корзины, выход из оболочки.
* **Встроенный калькулятор**: вычисление математических выражений на лету с копированием результата в буфер обмена по `Enter`.
* **Быстрые префиксы**: `?запрос` — поиск в Google, `$команда` — выполнение команды в PowerShell / Терминале.

### 3. 📌 Интерактивный Dock с физикой волны 120–165+ Гц
* Детерминированный расчёт центров иконок в `CompositionTarget.Rendering` без дрожания (`jitter-free`) с плавным косинусным увеличением и анимацией подпрыгивания (`bounce`) при запуске.
* **Живое управление иконками**:
  * Любое запущенное приложение автоматически появляется в динамической секции Dock со своей 256×256 иконкой и индикатором активности.
  * Через контекстное меню (ПКМ) можно **закрепить** любое запущенное приложение в Dock, **открепить**, **переместить влево / вправо**, открыть новое окно или закрыть процесс.
* **Умное автоскрытие**: Dock всегда виден на рабочем столе и автоматически уезжает вниз только тогда, когда активное окно развёрнуто на весь экран (с плавным появлением при наведении курсора к нижнему краю экрана).

### 4. 🖥 Верхняя панель меню (Top Menu Bar) и резервирование `WorkArea`
* Регистрирует системную панель через `SHAppBarMessage` и фиксирует рабочую область экрана (`SPI_SETWORKAREA`), чтобы развёрнутые окна и ярлыки рабочего стола никогда не перекрывались верхней панелью.
* Отображает имя активного окна, меню (`Файл`, `Правка`, `Вид`, `Переход`, `Окно`, `Справка`), загрузку ОЗУ в реальном времени, текущую раскладку клавиатуры (`RU` / `EN`), быстрый поиск, **Пункт управления** и **Календарь**.

### 5. 🧩 Настольные виджеты рабочего стола (Desktop Widgets)
* Закреплены на уровне рабочего стола (`HWND_BOTTOM`, позади всех обычных окон):
  1. **Виджет времени и телеметрии ПК**: часы, дата, живые индикаторы загрузки ОЗУ, свободного места на диске `C:` и числа активных окон.
  2. **Виджет «★ Быстрый запуск»**: плитки избранных приложений для запуска в 1 клик.
  3. **Виджет «📝 Заметки рабочего стола»**: редактируемое поле быстрых заметок с автосохранением в `config.json`.

### 6. 🗔 Обзор активных окон (`Window Switcher`) и Центр настроек (`Win + Shift + A`)
* **Обзор окон**: полноэкранная сетка всех открытых окон с иконками, заголовками, переключением в 1 клик, кнопкой закрытия окна `✕` и кнопкой «Свернуть все окна».
* **Настройки лаунчера (`LauncherSettingsWindow`)**: графический центр управления с 4 вкладками:
  * *Оболочка и вид* — включение/отключение модулей (Top Bar, Dock, Виджеты, Скрытие панели Windows, Перехват `Win`, Автозапуск), ползунки размера и увеличения Dock, галерея обоев 6K.
  * *Панель Dock* — сортировка (`↑`/`↓`), добавление `.exe` и удаление закреплённых элементов, сброс по умолчанию.
  * *Каталог программ* — добавление портативных `.exe` программ, пересканирование и управление скрытыми приложениями.
  * *Хоткеи и система* — памятка горячих клавиш, быстрый доступ к `config.json` и кнопка **«Выключить лаунчер и вернуть панель Windows»**.

## ⌨ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| **`Win`** *(одиночное нажатие)* | Открыть / закрыть полноэкранный лаунчер **«Приложения»** |
| **`Alt + Пробел`** | Открыть **Командную палитру и Быстрый поиск** |
| **`Win + Shift + A`** | Открыть **Настройки лаунчера** (`LauncherSettingsWindow`) |
| **`ПКМ` по приложению / иконке Dock** | Контекстное меню (Закрепить в Dock, Избранное, Запуск от Админа, Папка файла) |
| **`Колесо мыши` / `←` `→` / `PgUp` `PgDn`** | Переключение страниц в меню «Приложения» |
| **`Esc`** | Закрыть активное всплывающее окно / лаунчер / обзор окон |

## 🛠 Установка, сборка и запуск

Проект **не требует** установки Visual Studio или тяжеловесных SDK — сборка выполняется встроенным в любую Windows 10/11 компилятором `.NET Framework 4.x` (`csc.exe`).

### Быстрый запуск
```powershell
git clone https://github.com/sosiskacorp/TahoeLauncher.git
cd TahoeLauncher

# Сборка из исходного кода (создаёт MacOSTahoe.exe)
powershell -ExecutionPolicy Bypass -File .\build.ps1

# Применение оформления и запуск лаунчера
powershell -ExecutionPolicy Bypass -File .\apply.ps1
```

### Параметры командной строки `MacOSTahoe.exe`
* `MacOSTahoe.exe` — стандартный запуск оболочки и лаунчера
* `MacOSTahoe.exe --settings` — запуск с открытием окна «Настройки лаунчера»
* `MacOSTahoe.exe --launchpad` — открыть полноэкранное меню «Приложения»
* `MacOSTahoe.exe --search` — открыть командную палитру и быстрый поиск
* `MacOSTahoe.exe --windows` — открыть обзор активных окон
* `MacOSTahoe.exe --quit` — корректно завершить работу лаунчера и вернуть стандартную панель задач Windows 11

### Полный выход и возврат стандартного вида Windows 11
Вы можете в любой момент нажать **«Выход из лаунчера»** в системном меню верхней панели (или в окне настроек `Win+Shift+A`), либо выполнить скрипт:
```powershell
powershell -ExecutionPolicy Bypass -File .\revert.ps1
```
